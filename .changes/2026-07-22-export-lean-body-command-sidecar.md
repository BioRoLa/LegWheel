# 2026-07-22 — Export aligned Lean body-command sidecar

**Type:** feat

**Scope:** pose, csv

## Changes

- `PosePlanner.plan_sequence()` now retains the effective commanded body pose for every IK frame in `POSE_CMDS`.
- `generate_lean_csv()` writes an aligned `*_body_command.csv` beside the existing hardware CSV.
- Sidecar columns are `source_row`, `time_s`, `phase`, `height_m`, `roll_rad`, `pitch_rad`, `yaw_rad`, `x_m`, and `y_m`.
- Joint-space prep rows remain aligned but use `phase=prep` and NaN body-pose values; Lean rows use `phase=lean` and contain the exact pose supplied to IK, including height compensation.
- Added a regression test for row alignment, prep representation, timestamps, and commanded pitch/height values.

## Decisions

- Preserve one-to-one row alignment with the hardware CSV so archived command sequence indices can map directly to body commands.
- Do not infer a body pose for the prep transform because it is generated by joint-space interpolation and does not have a unique planner-level Lean command.

## Tracking impact

- Future Lean/Rock experiments can archive exact body-level commanded references instead of fitting a reference waveform to measured motion.
